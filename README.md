## Konsep HTTP Request dan Response

HTTP adalah aturan komunikasi antara browser (client) dan server web.

- **HTTP Request**: permintaan dari browser ke server, misalnya saat membuka halaman atau mengirim form. Berisi metode (GET untuk mengambil data, POST untuk mengirim data), alamat URL, dan header.
- **HTTP Response**: jawaban dari server ke browser. Berisi status code (200 berhasil, 404 halaman tidak ditemukan, 500 error server) dan isi halaman (HTML).

Alurnya: browser mengirim Request, server memproses, lalu server mengirim Response yang ditampilkan browser.
